# Readest 调试 MCP — 方案二第一期（只读）

## 目标
app 内建 dev-only 调试 HTTP 服务（仅 Windows 桌面、feature 门控、release 构建完全不含），独立 Node MCP server 把它暴露为 MCP tools，供 AI 在运行时查询：窗口列表、每窗打开的书与实时进度、浏览器 console 尾巴、窗口生命周期事件流。动作工具（open book / 跳转 / reload）留二期。

## 架构
```
[Tauri app]  debug_server.rs (feature "debug-mcp")
  tokio TcpListener 127.0.0.1:9339（env READEST_DEBUG_PORT 可改）
  鉴权 Bearer <uuid-v4 随机 token>
  GET /health | /state | /logs?n= | /events?since=
  发现文件 <log_dir>/debug-mcp.json {port, token, pid}   ← %APPDATA%\com.bilingify.readest\logs
  前端 dev-only 推送（window.__READEST_DEBUG__ 门控）:
    console 补丁 + 节流推送 zustand 状态 → 2 个新命令 → Rust 环形缓冲
[packages/readest-mcp]  stdio MCP server（@modelcontextprotocol/sdk）
  tools: readest_state / readest_logs / readest_events
```
